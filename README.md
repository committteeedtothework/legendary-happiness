DCSMCRAFT 2.18.0 adds 64 achievements across Survival, Equipment, Adventure, Ocean, custom DCSMCRAFT items/Stands, and Titans. Open Pause → Achievements to browse goals, search, filter and check progress. Unlocks have queued notifications and save per player/world.

Includes familiar Minecraft-inspired goals plus the Devin Sword, Matthew's pistols, Hellfire gear, Stands, custom bosses, Super Sonic moves, and separate Giganto/Wyvern victories. Minecraft reference sources and all actual requirements are in ACHIEVEMENTS.md. This is a selection adapted to supported mechanics, not the complete official list or a platform achievement service.

Existing worlds are supported. Carried Survival equipment, existing Stands and proven Titan victory ledgers can backfill; past crafts, kills and furnace actions cannot be reconstructed. Progress survives respawn, arena reload/return and backup export/import. Co-op is host-authoritative and tracks the acting peer separately. Existing artwork/music, generation 16, combat balance and normal game rules are preserved.

Validation: 947 unit tests, 11 browser scenarios and matching Linux Electron tests. Native Windows execution and physical controller/iOS hardware remain unverified on this Linux host. Windows executables are unsigned. Runtime and HTML-launcher payloads are extracted/hash checked against tested game content; public downloads are checksum verified.

Separate Windows choices: bundled runtime EXE, or the previous Windows HTML launcher ZIP requiring installed Edge/Chrome. Both contain the same game. Their DesktopApp/DesktopProfile saves are separate; use world backup export/import to switch. Standalone Browser, complete Source, and Verification ZIPs are also provided.

Reference research: https://minecraft.wiki/w/Achievement and https://minecraft.wiki/w/Advancement (plus the vanilla language-resource mirror recorded in source). The default branch and hosted mobile build stay unchanged.
