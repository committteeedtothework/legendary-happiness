# DCSMCRAFT 1.4.1 downloads

This branch distributes the verified DCSMCRAFT 1.4.1 build files without changing main or the local game source.

Download DCSMCRAFT-Windows-1.4.1.zip for Windows 10/11, extract it, and run DCSMCRAFT.exe. The unsigned launcher requires installed Edge or Chrome.

Complete game source, assets, dependency manifests, tests, launch instructions and the partial/missing feature checklist are in dcsmcraft-source-v1.4.1.zip. Reference mechanics: Minecraft Java Edition 1.20.4, with partial parity. The HTML build is self-contained. Hosting multiplayer requires Node.js; the optional public tunnel also requires cloudflared.

Validation: 299 core tests and five selected browser scenarios passed. Native Windows execution and live Cloudflare tunneling were not verified on this Linux host.
