DCSMCRAFT 2.2.2 — Classic Arm Repair

First-person hands return to simple square voxel arms. Separate finger bars, knuckles and thumbs are removed. Skin and sleeve use equal widths and meet exactly, and gloved skins replace the skin section instead of intersecting it. Item sockets fit the block hand, including both pistols. Empty hands and held items retain conservative camera clearance. Smooth action curves, sway, equip transitions, recoil and swimming remain.

Existing worlds work without regeneration. All other runtime modules/assets are byte-identical to 2.2.1; the data file changes only the release version. Gameplay, world generation, saves, controls, combat timing, first/third-person action curves, weapon models, audio, local discs, Creative Stands and multiplayer are unchanged.

398 core tests and five targeted offline browser scenarios pass, including full action sweeps, all catalog grips, real melee hits, F5, independent pistol recoil, gloved/empty arms, item swaps and actual water swimming/land recovery. The new arm scenario was repeated against the final packaged HTML. Screenshots were visually inspected. Source ZIP entries match all 415 frozen input hashes; ZIP CRCs, 189 supplied PNGs and embedded executable HTML are verified. Native Windows execution remains unverified on this Linux build host; installed Edge or Chrome is required. Testing does not establish a zero-bug guarantee. Reference remains Minecraft Java 1.20.4, with partial baseline parity.
