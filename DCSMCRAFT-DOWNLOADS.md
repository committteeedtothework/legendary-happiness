# DCSMCRAFT 1.6.1 — Guardian Seal

Download the Windows ZIP, extract it and run DCSMCRAFT.exe. The standalone HTML remains self-contained. Requires installed Edge or Chrome for the Windows launcher.

The planted Devin Sword now requires **all three distinct temple Guardians to be defeated** before extraction can begin, including Creative and Peaceful. The inner seal no longer opens solely because the mode/difficulty changes. Duplicate or invalid defeat records and stale records with living Guardians cannot unlock collection. Only actual dead temple Guardians with valid role indices count toward victory.

Legitimate saved defeats still count; previously claimed swords remain claimed. The Cinder Sigil approach, actual 30-second extraction, unique claim and other game mechanics are retained. Pre-temple worlds keep their original relics because they have no Guardians. Creative catalogs and owner cheats remain unrestricted tools; this gate applies to the planted temple relic. Existing saves work and no new world is required.
