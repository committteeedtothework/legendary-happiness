- Windows 10/11 x64: extract DCSMCRAFT-Windows-2.8.18.zip and run DCSMCRAFT.exe with Edge or Chrome installed.
- Browser: extract DCSMCRAFT-Browser-2.8.18.zip and open DCSMCRAFT.html. Singleplayer assets are embedded.
- Source: dcsmcraft-source-v2.8.18.zip contains source, assets, dependency lock and build instructions.
- Screenshots: DCSMCRAFT-Screenshots-2.8.18.zip contains actual game captures and verification reports.

Read GIGANTO-RETURN-PORTAL.md and VALIDATION.md for tests and limitations. The portal is a stylized effect, not a live view into the world.
