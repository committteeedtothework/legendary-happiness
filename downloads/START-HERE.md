# DCSMCRAFT 2.8.14 downloads

This Giganto-only release upgrades the arena terrain, ground/rock shading, groves and wind, sky/clouds and distant water, model/material lighting, shadows, cinematic camera tracks, boss HUD and localized impact effects. New arena-only graphics settings include resolution scale, foliage, exposure, bloom, atmosphere, impact sparks, cinematic camera and letterbox. Overworld gameplay/assets/save formats are unchanged.

- Windows 10/11 x64: extract DCSMCRAFT-Windows-2.8.14.zip and run DCSMCRAFT.exe with Edge or Chrome installed.
- Browser: extract DCSMCRAFT-Browser-2.8.14.zip and open DCSMCRAFT.html; assets are embedded for offline singleplayer.
- Source: dcsmcraft-source-v2.8.14.zip includes source/assets, dependency lock and build instructions.
- Screenshots: DCSMCRAFT-Screenshots-2.8.14.zip contains the actual in-game PNGs, before images, a local gallery and the capture report. Individual final images are also in screenshots/ on this branch.

Use the same browser/profile/file location for existing local saves, or export/import a world backup when moving. Save formats remain unchanged.

745 unit tests, 22 standalone browser scenarios and one production smoke pass. One direct-file case is skipped by managed browser policy; native Windows execution is untested. The launcher embeds/extracts the tested HTML. Original procedural scenery and camera choreography approximate Sonic Frontiers; full commercial asset/animation fidelity remains unfinished. Read GIGANTO-PRESENTATION.md for changed files, controls, results and limits.
