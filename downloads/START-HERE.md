# DCSMCRAFT 2.8.21 downloads

Giganto has 48,000 HP on Normal with stronger Super Sonic attacks, directional flight and full-body ability poses. Super Sonic no longer has a following blue speed ribbon. Base Sonic can hold C while circling grass to release collectible rings. Arena grass/filtering and per-frame work are refined. Overworld gameplay, assets, music timestamps, objectives and the ending/return portal remain.

- Windows 10/11 x64: extract DCSMCRAFT-Windows-2.8.21.zip and run DCSMCRAFT.exe with Edge or Chrome installed.
- Browser: extract DCSMCRAFT-Browser-2.8.21.zip and open DCSMCRAFT.html. Singleplayer assets are embedded.
- Source: dcsmcraft-source-v2.8.21.zip contains source, assets, dependency lock and build instructions.
- Screenshots: DCSMCRAFT-Screenshots-2.8.21.zip contains actual game captures and verification reports.

Read GIGANTO-FLIGHT-CYLOOP.md and VALIDATION.md for tests and limitations. Native Windows launch is untested on Linux; embedded extraction is verified.
