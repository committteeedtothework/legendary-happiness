- **Three.js 0.180.0** — MIT, copyright three.js authors. WebGL renderer and mathematical utilities. Upstream license: `node_modules/three/LICENSE`. Bundled in the production build.
- **ws 8.18.3** — MIT, copyright Einar Otto Stangvik and contributors. Optional Node.js multiplayer relay only; not included in the offline browser runtime. Upstream license: `node_modules/ws/LICENSE`.
- **Vite 7.1.12** — MIT, copyright Vite contributors. Development server/build tooling; transitive build tooling licenses are in installed dependencies.
- **Playwright Test 1.56.1** — Apache-2.0, copyright Microsoft Corporation. Development-only browser tests.

The exact dependency graph and package integrity hashes are in `package-lock.json`. Install with `npm ci`.

The project's default voxel textures, item sprites, simple creature models, icons, interface design and synthesized game sounds are generated by original source in this repository. The optional Supplied Assets pack is the exception described below. System font stacks require no font download. The Minecraft name identifies the requested mechanics reference (Java Edition 1.20.4) and supplied texture source; DCSMCRAFT is an independent project and is not affiliated with Mojang or Microsoft.

Desktop builds use the Zig compiler distributed as `@oven/zig-linux-x64@0.12.0-dev.1286` (development tool only; it is not embedded in the game). The Windows launcher links only normal Windows system libraries. Its rendering runtime is the user’s installed Edge/Chrome engine. The original pixel font is generated by `scripts/generate-font.py` using FontTools as an optional asset-development tool; the font itself and its outline designs are original project assets.

Historical retired jukebox integration (removed in 2.2.1; current discs play local MP3s): the older jukebox used the hosted YouTube IFrame Player API and a visible youtube-nocookie.com video embed after an explicit Play click. This external service requires internet, contacts YouTube/Google and is subject to its terms, privacy rules and video-owner restrictions. No API key, downloaded/extracted stream, third-party music, SDK copy or media proxy is bundled. YouTube content remains on its provider. The deterministic player fixture is test-only.

Optional public PC hosting invokes the separately installed Cloudflare `cloudflared` utility and Quick Tunnel service only when HOST-PUBLIC is explicitly run. Neither its executable nor provider implementation is bundled. Installation, current license/service terms and limits are available from the official Cloudflare project/download documentation. No always-on public relay account or third-party certificate/private key is included. Test provider processes and self-signed test certificates are validation fixtures only.

## Optional user-supplied texture artwork — 1.8.1

The selectable **Supplied Assets** pack imports 183 PNGs from the user's `assets.zip`, under `assets/minecraft/textures/block/` and `assets/minecraft/textures/item/`. These Minecraft images belong to **Mojang/Microsoft**; they are not original project artwork or licensed under the project's MIT license. All rights of the respective owners are retained. No independent redistribution license was present in the supplied archive. The pack is optional and off by default. DCSMCRAFT remains unaffiliated with Mojang/Microsoft.

`public/supplied-pack/manifest.json` records every selected PNG's original path/hash/dimensions, the archive hash, frame-zero selection and any base tint. Original selected PNGs are preserved there; the game embeds lossless RLE pixels (including alpha) through `src/supplied-pack-data.js`. The archive's JSON, text, shaders and other contents are not executed or imported. `public/SUPPLIED-ASSETS-NOTICE.txt` is also embedded in the standalone HTML, carried inside the Windows executable, and copied into desktop notices. Original pack fallbacks, creature/weapon models, fonts and sounds retain their existing licenses.
